# Data & evaluation protocol

## 데이터 가정

- 학습: 532개 연속 날짜, 193개 동일 메뉴의 일별 판매량 완전 패널.
- CSV 컬럼: `영업일자`, `영업장명_메뉴명`, `매출수량`.
- `영업장명_메뉴명`은 **첫 번째** `_`에서만 분리해 영업장 이름을 얻는다.
- 음수 판매량 14건은 원본에서 유지. LightGBM 최종 예측값은 음수일 때 0으로 clip.

## 시계열 학습

각 train cutoff `t`: `[t-27, ..., t]` 28일 이력으로 `t+1`~`t+7`을 예측하도록 지도 학습. 검증 cutoff `T`의 train cutoff들은 `t+7 <= T`를 만족해야 함. 같은 메뉴의 중복되는 28일 이력 윈도우를 사용해도 미래 정답을 사용하지 않으면 그 자체로 누수는 아님.

## 내부 평가

`SMAPE(y,p) = 2 * |y-p| / (|y|+|p|)`; 실제 0인 관측치를 제외. `(y!=0)`과 `(y>0)`을 민감도 분석했으며 기존 11-fold에서 유효 관측치는 각각 7,445 / 7,444.

- Fold Pooled: 유효한 개별 관측치에 대한 SMAPE 평균.
- Fold Store-Macro: 각 영업장에서 유효 관측치 SMAPE 평균을 내고 영업장 평균을 구함. 유효 관측치가 없는 영업장은 해당 Fold에서 제외.
- 11-fold mean: 각 Fold 점수를 동등하게 평균.
- All observation pooled: Fold 구분 없이 모든 유효 관측치 평균.

**대회 지표 복제 아님**: 정확한 영업장별 가중치는 공개되지 않았으므로 본 프로젝트의 Store-Macro는 단순 대리 지표.

## Test-time 원칙

- 테스트 파일 10개 각각을 독립적으로 읽음.
- 각 샘플에 포함된 28일 판매량 외 타 테스트 샘플 예측 결과나 미래 정보를 입력으로 사용하지 않음.
- 정확한 메뉴 이름과 제출 템플릿 열 순서 유지.
- `TEST_00+1일` ~ `TEST_09+7일` 각 70행 생성.

## Train-serving parity

학습 피처 생성과 추론 피처 생성이 동일 28일 구간에서 모두 같은 값을 내는지 테스트한다. `horizon`, `weekday`, `month`, `mean7`, `mean28`, `std7`, `zero_ratio28`, `positive_days28`, `weekday_mean4`, `lag7`, `lag14`.
