# Experiment Log — 의사결정의 근거

수치는 로컬 실험에서 공유된 출력값입니다. 작은 차이는 내부 SMAPE 정의, fold 집계, 학습 라이브러리 버전에 영향받을 수 있습니다.

## 개발 평가 Fold

`2023-07-31`, `08-31`, `09-30`, `10-31`, `11-30`, `12-31`, `2024-01-31`, `02-29`, `03-31`, `04-30`, `05-31`. 각 Cutoff 다음 7일에 대해 평가. 훈련 데이터는 해당 Cutoff 시점에 이미 정답이 알려진 창만 사용.

## 1. 단순 기준선

11-fold Pooled SMAPE 평균: B0 `mean28` **0.7181**, B1 `mean7` **0.6974**, B2 전주 동일 요일 **0.9498**, B3 과거 4주 동일 요일 **0.7952**. B1이 평균적으로 가장 유리하지만 Fold별 변동이 커 비교 기준을 여러 개 유지.

## 2. Global LightGBM과 영업장

- ML001: **0.6567** (std .0888). Full: `menu_id`, `horizon`, `weekday`, `month`, `mean7`, `mean28`, `std7`, `zero_ratio28`, `positive_days28`, `weekday_mean4`.
- ML002 (`store_id` 추가): **0.6629** (std .0908), 개선 3/11 Fold.
- `store_id`는 `menu_id`에서 결정되므로 이미 정보가 중복됨. 그렇다고 동적 영업장 피처나 Local 모델이 무용하다는 뜻은 아님.
- 영업장별 오류 분석: 특정 영업장이 모든 시점에서 계속 실패한다는 강한 증거는 없었고, 2024-01-01~07 및 2024-03-01~07에 다수 영업장에서 동시에 성능 악화.

## 3. 학습 Cutoff 구성

- Weekly (`idx=27,34,...`): 평균 **0.6567**.
- Daily (매일): 평균 **0.6609**, 개선 6/11 Fold. 7배 가량 더 많은 중첩 샘플을 쓰는 것만으로 일반화 성능이 개선된다는 증거 없음.
- Rotating(주별 다른 요일 선택)은 4개 Fold 평균 **0.7412** vs Weekly **0.6966**. 주별 날짜 구성·겹침이 함께 변하는 설계였으므로 요일 다양성의 독립 효과라고 해석하지 않음.

## 4. Feature Ablation

| 설정 | Pooled 평균 | 변화 vs Full |
|---|---:|---:|
| Full | 0.6567 | 0 |
| No_menu_id | **0.6395** | -0.0172 |
| No_month | 0.6468 | -0.0099 |
| No_weekday, No_weekday_mean4 | 0.7334 | +0.0767 |

`No_menu_id`는 Full 대비 **9/11 Fold**에서 Store-Macro 개선, Store-Macro **0.6472** vs Full **0.6725**. `month`는 평균 개선되었으나 7/11 Fold에서 제거 모델이 악화되어 명확한 제거 결정은 보류.

## 5. Lag와 희소성

- `lag7`,`lag14` 추가: NoID **0.6395 → 0.6342** Pooled, Store-Macro **0.6472 → 0.6418**, 개선 9/11 Fold.
- `zero_streak28` 추가: Pooled **0.6342 → 0.6385**, Store-Macro **0.6418 → 0.6488**, 제외.

## 6. 손실함수

- L2/MSE: Pooled **0.6342**, Macro **0.6418**.
- L1/MAE: Pooled **0.9107**, Macro **0.9373**. 모두 11개 Fold에서 악화.
- 예측 분포 진단(3개 Fold 평균): 실제 양수 날에 `pred < 1` 비율 MSE **17.91%**, MAE **38.67%**. MAE가 과소예측한다는 설명과 부합하나 이것만으로 모든 악화 원인을 확정할 수는 없음.

## 7. Zero-target 학습 정책

| 정책 | Pooled 11-fold | Store-Macro 11-fold |
|---|---:|---:|
| All MSE, zero weight 1.0 | 0.6342 | 0.6418 |
| Zero weight 0.5 | 0.6000 | 0.6019 |
| Zero weight 0.25 | **0.5811** | **0.5784** |
| Positive-only | 0.5980 | 0.5897 |

`0.25`가 3개 가중치 중 Macro 기준 최저인 Fold 8/11; `1.0` 대비 10/11 Fold 개선. 그러나 가중치가 낮을수록 실제 0인 날의 예측 판매량이 높아지는 경향이 관찰됨. **실제 수요/발주 목표와 대회 점수 목표의 괴리**.

## 8. 마지막 7일 Holdout

Cutoff 2024-06-08, 입력 2024-05-12~06-08, 정답 06-09~06-15.

| 정책 | Holdout Pooled | Holdout Store-Macro | 실제 0인 날 평균 예측 |
|---|---:|---:|---:|
| All MSE | 0.6474 | **0.6058** | 2.6113 |
| Zero weight 0.25 | **0.6422** | 0.6172 | 4.7686 |
| Positive-only | 0.6767 | 0.6543 | 11.2334 |

상반된 결과: `0.25`는 pooled에서 미세하게 우세하지만 Store-Macro에서는 불리. 영업장별로 이익과 손실이 다름(예: 포레스트릿 `All .4269 / Weighted .5738`; 미라시아 `All .6238 / Weighted .5811`). Holdout 결과를 본 뒤 그 기간을 이용하여 가중치를 다시 고르지 않음.

## 9. 추론과 제출

학습용과 추론용 11개 피처의 `max_absolute_difference = 0` (2024-05-31 Cutoff에서 점검). TEST 각 28일을 독립적으로 사용하여 7일 예측, 10개 TEST × 7일 × 193메뉴 = 13,510개 값. 실제 제출: Public **0.5653057744**, Private **0.5528701672**.

## 해석의 한계

- 내부 지표에서 `y != 0`으로 평가(별도 양수만 평가 민감도 차이는 미미). 정확한 대회 영업장 가중치는 비공개.
- 동일한 개발 Fold를 반복 사용한 모델 선택 편향 가능성.
- 마지막 7일 Holdout은 한 기간이므로 장기적 일반화의 확정 증거가 아님.
- TEST 정답이 없으므로 제출 예측의 영업장별 오차 원인을 직접 확인할 수 없음.
